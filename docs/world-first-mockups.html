6 states, 1 canvas, 0 bottom tabs

What changed & canonical spec.md rules folded in

  • Bottom tab bar deleted (+64 px vertical stage): Kids land immediately in the 3D world instead of scrolling past 124 engineering check rows in Toybox.
  • Top dock fits 390 px with zero horizontal scroll: [Kip ▾], Build, Create, Pack, and ⋯ replace the 9-button horizontal scroll strip.
  • AR View + Stud Grid (BuilderCanvas) + hard-gated STL: Build keeps stud/hole snapping & the 4 live green checks via a compact toggle, hides .stl downloads until all checks pass, and shows 0.2 mm PLA prototype + 3+ small-parts notices.
  • Character Reveal plays once per new build: Tapping Done in Build auto-opens Character Card once for a new build signature; replays stay manual in ⋯ -> Character Card.
  • Meta SAM 3.1 Scan + 1-tap demo backup: Photo + Object chip + S/M/L pill + Outline with Meta SAM 3.1, plus a quiet 1-tap Red Racer / Kip backup row if live camera is unavailable.
  • Privacy & copy hygiene: Push-to-talk parent-started mic (moods work with mic off), consistent Meta SAM 3.1 & Meta Muse naming, and zero em dashes anywhere on screen.
