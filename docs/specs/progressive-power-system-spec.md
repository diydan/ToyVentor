A module-`2.5` `gear_spur_z10` on the Core output shaft at **`Z_pto = 31.25 mm`** (`18.75 mm` above `Z_deck = 12.50 mm`; gear top at `Z_world = 46.25 mm`, clearing the `Z_world = 48.00 mm` lid ceiling by **`+1.75 mm`**) meshes at `31.25 - 6.25 = 25.00 mm` (`2.0 TU`) above the deck (`Z_world = 16.25 .. 21.25 mm`). 4. **`100%` Above-Deck (`Z_world >= 12.50 mm`) Wire Routing — Zero Keel/Axle Intersection:** `#1 kit_keel_base` has **no** internal cable channels (`Z_world = 0.00 .. 12.50 mm` remains a solid slab with `+2.95 mm` solid deck above `Z_world = 9.55 mm` rotating shafts and `1.30 mm` roof above `Z_world = 11.20 mm` teardrops). 5. **Relieved `Ø8.20 mm` Central Tunnels Between `3.00 mm` Outer Bearing Lands:** Eliminates FDM over-extrusion bore drag across `49.8 mm` spans (`F1` friction logged empirically).
