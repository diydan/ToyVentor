### 1.1 Five Future-Proof Features Locked Into `#1 kit_keel_base` & Cockpit Modules Today

A module-`2.5` `gear_spur_z10` on the Core output shaft at **`Z_pto = 31.25 mm`** (`18.75 mm` above `Z_deck = 12.50 mm`) meshes at `31.25 - 6.25 = 25.00 mm` (`2.0 TU`).
