🤖 Conforming LLM Part-Maker SDK (PartSpec v2)

Any LLM can author 100% support-free, lattice-verified ToyVentor parts using kip_partspec_sdk.py (crown_addon, character_head, backpack_addon, handheld_prop, vehicle_addon) and validate them through toyventor_parts.evaluate() + toyventor_assembly.validate().

Validate locally: npm run kip:validate-part -- my_part.py
from kip_partspec_sdk import * def build(): return crown_addon(loft_slabs([(0,23.6,11.6,4.8), (7,28,17.2,6.5,0,-1.5), (23.5,6.2,6.2,2.8,1.8,1.2)])) PART = part_spec(id="custom_wizard_hat", name="Starlight Wizard Hat", stat="Glow", behavior="...", slot="crown", fn=build) if __name__ == "__main__": run_cli(PART)
