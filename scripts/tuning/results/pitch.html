Forge: type a wish, wear it, print it

You open Make from words and type what you want to wear, like a pink princess hat or I want to be a frog. It thinks for about 10–15 seconds and shows a little hat or animal head that fits your toy. You preview it, try it on, then print it with a grown-up's OK to snap onto the real toy. A brand, rude word, or phone number just gets a calm no and another try.

ToyVentor Forge · hackathon pitch · 16 eval runs (v2 below) · 2026-11-04

How it works

Wish → Muse Glimmer 30B (self-hosted LoRA) → one small JSON recipe + 7-language names → deterministic compiler + print gates → printable STL. The model never emits mesh; code builds and checks it. Scope now: crown (hat) or head only; vehicle slots and hand still go to the base. One wish = one call; a repair resends the failed recipe with gate feedback, max 4 tries.

How it was trained

QLoRA fine-tune (Unsloth, Modal L40S/H100, 1–2 epochs, LR 2e-4, reasoning strength low) on 910 → 1,014 → 1,754 wish→recipe pairs. Every example passed production intake, print gates, recipe allowlist, and 7-language unsafe + brand filters. No hosted-model output, no child text in training. Judged on the same 243 wishes per run vs the untuned base: latency, printable share, first-call share, name-filter fixes, 70-item red-team. Blind dev (204) + 38-prompt slot probe are pointers.

Training: learned, not memorised

Headline result (v2) — pilot 8 passes, on the line

Quality held: printable 100 → 98.8 / 98.8; first-call 94.4 → 96.9 / 96.9. v1: p6 speed 3/3, safety 0/3; prefill control fast (12.1 s) but broken (printable 96.9%, filters 22, red-team 57/70). Full matrix: charts.html §4.

Noise ≈ the margin — one run can't prove it

  • Blind dev (unseen brands): p8 76.2%, one run — pointer only. Slot probe (38 non-hat prompts): base 38/38, p8 36/38, p6 34/38; ship routes non-hat/head to base.
  • Cost ~$68 Modal GPU. A pass = permission to run beside the base, not a child-safety claim.

Why we tuned it

  • Kids can't use the hosted model. Meta API terms bar under-18 end users and kid-targeted products, so the demo runs hosted with adults only and production must be self-hosted Glimmer.
  • Safety by construction, measured. Trained only on answers that already passed every gate, so it never saw a brand, unsafe, or refused wish — judged against the base on the same red-team.
  • A smaller job. One narrow recipe writer (~600-char prompt vs ~10k) — less to do, less to red-team.
  • Speed and cost. ~54% faster median (13.1 vs 28.4 s), tail halved, fewer tokens per call, 4-bit weights on scale-to-zero GPU. Sweep cost ~$68.

What ships

Fast-path router: tuned model first for hat/head first attempts only; base on any failure, repair, or other slot. Off unless FORGE_FAST_MODE + SELF_FAST_URL/MODEL are set.
